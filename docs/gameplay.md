# Геймплей

## Core Loop

```
1. Еженедельное планирование
   Игрок расставляет приоритеты семьи на неделю

2. Прямые команды (в любой момент)
   Игрок выбирает персонажа и отдаёт конкретное действие

3. Симуляция дня
   Персонажи следуют плану, если нет прямой команды
   Путешествия, усталость, деньги, расписание влияют на возможности
   Черты влияют на качество и побочные эффекты

4. События и решения
   Игра прерывается на важные события: предложения, кризисы, угрозы, возможности

5. Еженедельный отчёт
   Итоги: финансы, здоровье, стресс, отношения, навыки, репутация, бизнес, долги, риски
   Ежемесячный отчёт: крупные рекуррентные платежи, смещения в городской экономике
```

## Временные уровни

| Уровень | Содержание |
|---|---|
| **День** | Путешествия, работа, учёба, отдых, события, изменения здоровья и отношений |
| **Неделя** | Основная единица планирования: приоритеты, бюджет, образование, работа, документы, здоровье, долги |
| **Месяц** | Зарплаты, аренда, ипотека, кредиты, налоги, счета, прибыль бизнеса, изменения рынка |

## Система времени

```
TimeSystem
├── currentDateTime (игровые дата и время)
├── speed (Paused / Normal×1 / Fast×2 / VeryFast×4)
├── dayNightCycle
└── calendar (дни недели, события, праздники)
```

- Время идёт само, можно паузить и ускорять
- 1 реальная секунда ≈ 1 игровая минута при Normal
- День/ночь важен для расписания зданий и безопасности маршрутов

## Уровень 1: Еженедельный план

Еженедельный план снижает рутину. Он задаёт поведение персонажей по умолчанию и приоритеты домохозяйства.

**Примеры приоритетов плана:**

| Приоритет | Что делает |
|---|---|
| Фокус на работе | Максимум рабочих часов, минимум отвлечений |
| Фокус на учёбе | Приоритет образовательных задач |
| Снизить расходы | Персонажи выбирают более дешёвые варианты |
| Погасить долг | Свободные деньги идут на кредит |
| Поправить здоровье | Врач, спорт, отдых в приоритете |
| Поддержать отношения | Социальные взаимодействия в расписании |
| Развивать бизнес | Больше времени на управление бизнесом |
| Собрать документы | Очереди и визиты в гос. учреждения |
| Искать лучшее жильё | Персонаж изучает предложения |

---

## Уровень 2: Прямые команды

В любой момент игрок может выбрать персонажа и отдать конкретную команду.

**Прямая команда обязательна к исполнению, если:**
- персонаж жив и доступен
- цель или действие существует
- локация открыта или доступна
- есть маршрут
- у персонажа есть минимальные ресурсы для действия

**Черты не отменяют прямые команды. Они влияют на результат.**

Примеры:
- трудолюбивый персонаж учится эффективнее
- ленивый всё равно учится, но получает меньше и устаёт быстрее
- любящий риск может случайно открыть побочную возможность
- персонаж с плохой гигиеной хуже проходит собеседования
- бюрократический персонаж быстрее разбирается с документами

**Примеры прямых команд:**
- пойти на работу / учёбу
- найти работу
- посетить врача / больницу
- купить товары в конкретном магазине
- встретиться с человеком
- подать документы в гос. орган
- разобраться с судебным делом
- потренироваться / отдохнуть
- управлять бизнесом

## Задачи

```
Task
├── id
├── type → TaskType
├── targetBuilding → Building
├── assignedCharacter → FamilyMember
├── startTime
├── duration (игровое время)
├── progress (0–100%)
├── requirements
│   ├── skills{} (навык: минимальный уровень)
│   ├── money
│   ├── documents[]
│   └── relationships (нужен знакомый / связь)
└── outcomes
    ├── money
    ├── skillXP{} (навык: опыт)
    ├── relationshipChange{} (персонаж: +/- значение)
    ├── healthChange
    ├── stressChange
    └── eventTrigger (может запустить событие)
```

### Типы задач

| Тип | Примеры |
|---|---|
| **Работа** | Поехать в офис, провести встречу, сдать отчёт |
| **Учёба** | Посетить вуз, онлайн-курс, читать книгу |
| **Социальное** | Ужин с другом, свидание, вечеринка |
| **Быт** | Магазин, готовка, уборка |
| **Здоровье** | Врач, тренировка, сон |
| **Бизнес** | Управление бизнесом, встреча с инвестором |
| **Документы** | Подача заявления, регистрация, лицензия |
| **Правовое** | Суд, консультация с адвокатом |
| **Досуг** | Рыбалка, концерт, прогулка |

## События

Игра прерывается на события. Источники событий:

- черты и привычки персонажей
- возраст (вехи: совершеннолетие, пенсия)
- здоровье и стресс
- работа и бизнес
- долги и финансовое давление
- жильё и район
- отношения
- закон и репутация
- городская экономика
- прямые команды
- успехи или провалы еженедельного плана

**Примеры событий:**
- арендодатель поднимает ренту
- назначена проверка бизнеса
- ребёнок прогуливает занятия
- работа предлагает повышение с более длинным маршрутом
- банк предлагает рискованный кредит
- родственник просит деньги
- приходит судебная повестка
- район начинает джентрифицироваться
- сотрудник ворует из бизнеса
- старый долг всплывает снова

## Отчёты

### Еженедельный отчёт
- финансы (доходы, расходы, баланс)
- здоровье и стресс каждого персонажа
- прогресс навыков
- изменения отношений
- состояние бизнеса
- долги и риски
- крупные события прошедшей недели

### Ежемесячный отчёт
- все рекуррентные платежи (аренда, ипотека, кредиты, налоги, счета)
- прибыль / убыток бизнеса
- изменения в городской экономике
- рост или падение цен в районе

---

## Невозможные и опасные действия

- Если прямая команда физически невозможна — игра объясняет почему
- Если команда возможна, но вредна — игра разрешает её и применяет последствия
- Если семья не может платить — долг, штраф, выселение, правовые проблемы или потеря услуг
- Если персонажу не хватает документов, денег или квалификации — действие проваливается или создаёт событие
- Если персонаж умирает — наследство, горе, обязательства и структура семьи обновляются

## Конец игры и продолжение

- **Game Over:** все члены семьи умерли без наследников
- Возможное продолжение: через наследников, дальних родственников или новую ветвь
- Нет победы — sandbox
- В конце: статистика и хроника семьи
