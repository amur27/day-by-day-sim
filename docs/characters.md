# Персонажи

## Семья

- До **10 персонажей** под управлением игрока
- Переключение фокуса между персонажами в любой момент
- Персонажи **взрослеют и стареют** в реальном игровом времени
- Если все члены семьи умерли — **игра окончена** (если нет наследников или дальних родственников)

---

## Данные персонажа

Каждый персонаж содержит:

| Группа | Поля |
|---|---|
| **Идентичность** | имя, возраст, внешность |
| **Здоровье** | HP (физическое), энергия, настроение, стресс |
| **Образование** | уровень образования, посещаемые учреждения |
| **Занятость** | текущая работа или деятельность |
| **Характеристики** | 18 врождённых черт (0–100) |
| **Навыки** | навык → уровень (открытый список) |
| **Привычки** | сформированные паттерны поведения |
| **Отношения** | граф связей с другими персонажами |
| **Репутация** | в профессиональной, деловой, социальной среде |
| **Правовой статус** | документы, дела, штрафы, судимости |
| **Финансовые обязательства** | кредиты, алименты, долги |
| **Личные цели / тенденции** | что персонаж стремится делать по умолчанию |

---

## Создание персонажа

**Старт игры — выбор сценария:**

Игрок выбирает сценарий (пресет), определяющий:
- Район и жильё
- Состав семьи
- Наличные и долги
- Образование и работу
- Репутацию и правовые проблемы
- Стартовые возможности и социальные связи

После выбора сценария игрок может **отредактировать** семью:
- имена, внешность, возраст, состав
- черты, навыки, образование
- стартовые деньги, жильё, долги, часть отношений

Сценарий предупреждает, если правки делают старт значительно легче/сложнее.

**Примеры сценариев:**

| Сценарий | Описание |
|---|---|
| Одиночка с небольшими сбережениями | Чистый лист, средний капитал |
| Молодая семья с ипотекой | 2–3 персонажа, долг, спальный район |
| Три поколения в старой квартире | Сложная динамика, мало денег |
| Семейный бизнес у края банкротства | Есть актив, есть кризис |
| Недавно переехавшие в город | Нет связей, нет репутации |
| Наследники элитной семьи | Деньги, но дорогие привычки и ожидания |
| Семья с долгами и судебными делами | Тяжёлый старт, высокие ставки |

---

## Характеристики (врождённые)

Постоянные черты личности. Меняются незначительно в **дни рождения и возрастные вехи** (отражают жизненный опыт, воспитание, стресс, успехи и потери).

**Шкала:** 0–100

| Диапазон | Название |
|---|---|
| 0–20 | Ненавидит / избегает |
| 21–40 | Не любит |
| 41–60 | Нейтрально |
| 61–80 | Любит |
| 81–100 | Обожает / определяет личность |

**Черты работают на трёх уровнях:**

1. **Модификаторы** — влияют на скорость обучения, качество работы, стресс, здоровье, расходы, риск, общение, бюрократию и другие системы
2. **Автоматическое поведение** — при действии по еженедельному плану персонаж следует своим чертам в том, как выполняет рутину
3. **События** — экстремальные или релевантные черты разблокируют события, кризисы, возможности, конфликты и дилеммы

**Список характеристик:**

| Характеристика | Описание влияния |
|---|---|
| Трудолюбие | Скорость и качество рабочих задач, усталость от работы |
| Бюрократизм | Эффективность работы с документами, успех в гос. структурах |
| Отношение к закону | Склонность к нарушениям, реакция на штрафы и проверки |
| Отношение к шоппингу | Частота импульсивных покупок, настроение от шоппинга |
| Аналитические способности | Скорость изучения интеллектуальных навыков |
| Отношение к комфорту | Насколько важен уровень жилья, транспорта и условий жизни |
| Отношение к престижу | Реакция на статус работы, района, вещей, социального окружения |
| Креативность | Скорость освоения творческих навыков |
| Отношение к алкоголю/стимуляторам | Частота употребления, эффект на настроение и здоровье |
| Любовь к спорту | Удовольствие от физической активности, скорость спортивных навыков |
| Отношение к технологиям | Скорость освоения технических навыков, реакция на гаджеты |
| Отношение к гигиене | Важность чистоты, последствия её отсутствия (карьера, отношения) |
| Любовь к общению | Частота социальных потребностей, скорость роста отношений |
| Духовность | Реакция на духовные практики, кризисы и потери |
| Любовь к еде | Удовольствие от типа пищи, скорость голода |
| Любовь ко сну | Потребность в отдыхе, реакция на недосып |
| Любовь к езде | Удовольствие от транспорта, стремление к личному автомобилю |
| Отношение к риску | Склонность к авантюрам, инвестициям, опасным решениям |

> Длительное противоречие между поведением и чертой может сдвинуть черту (в любую сторону). Это происходит медленно и отражает реальный жизненный опыт.

## Жизненные параметры

Два ключевых показателя жизни. Если любой из них достигает нуля — персонаж умирает.

| Параметр | Описание | Что дренирует |
|---|---|---|
| **HP** (физическое здоровье) | Физическая жизнеспособность | Голод, истощение, болезни, травмы |
| **MP** (духовное здоровье / счастье) | Психологическая устойчивость | Депрессия, высокий стресс, изоляция, тяжёлые потери |

HP = 0 **или** MP = 0 → персонаж умирает.

---

## Базовые потребности

Потребности сами по себе не убивают. При обнулении они начинают медленно дренировать HP или MP.

| Потребность | Дренирует | Эффект при нехватке |
|---|---|---|
| **Питание** | HP | Голод снижает физическое здоровье и концентрацию |
| **Энергия** (сон) | HP + MP | Истощение бьёт по обоим параметрам жизни |
| **Настроение** | MP | Депрессия подтачивает духовное здоровье |
| **Стресс** | MP | Накапливается от долгов, конфликтов, перегрузок. При >80 дренирует MP. При >95 — возможны события (срыв, болезнь) |

Стресс растёт, остальные потребности падают — направление противоположное.

Черты усиливают или ослабляют эффект. Пример: «обожает еду» (81–100) — нездоровая еда поднимает настроение, но медленно снижает HP.

## Навыки (приобретённые)

Разблокируются через обучение, практику и задачи.

**Роли навыка:**
1. **Порог** — минимальный уровень для доступа к задаче, должности или учреждению
2. **Модификатор качества** — чем выше навык, тем лучше/быстрее выполняется задача

**Список открытый.** Примеры категорий:

| Категория | Примеры |
|---|---|
| Интеллектуальные | Программирование, аналитика, изучение языков, шахматы |
| Творческие | Рисование, музыка, пение, писательство |
| Физические | Бег, боевые искусства, футбол, плавание |
| Практические | Готовка, вождение, ремонт, рыбалка |
| Социальные | Переговоры, харизма, лидерство |
| Профессиональные | Бухгалтерия, менеджмент, юриспруденция, медицина |
| Бюрократические | Работа с документами, знание законов, налоговая отчётность |

---

## Привычки

Формируются при многократном повторении действий. Влияют на поведение персонажа по еженедельному плану.

Привычки могут быть:
- положительными (ранний подъём, регулярные тренировки, экономия)
- отрицательными (импульсивные покупки, злоупотребление алкоголем, прогулы)

Привычка меняет вероятность выбора действия в свободное время и модифицирует расход ресурсов.

## Отношения

Граф связей: семья + знакомые.

**Типы связей:**

| Тип | Описание |
|---|---|
| Супруг/супруга | Партнёр |
| Родитель / ребёнок | Семейная иерархия |
| Брат / сестра | Сиблинг |
| Родственник | Дальний родственник |
| Друг | Личная привязанность |
| Коллега | Рабочая связь |
| Начальник / подчинённый | Профессиональная иерархия |
| Сосед | Территориальная связь |
| Наставник / ученик | Передача знаний |
| Полезный контакт | Инструментальная связь |
| Враг | Негативная связь |

**Глубокие значения (там, где создают интересный геймплей):**

| Поле | Описание |
|---|---|
| trust | Доверие |
| respect | Уважение |
| tension | Напряжение |
| influence | Влияние одного на другого |
| compatibility | Совместимость характеров |
| resentment | Обида (накапливается от конкретных событий) |
| obligation | Долг или обязательство перед другим |
| socialReputation | Репутация внутри социального круга |

Черта «Любовь к общению» влияет на скорость роста trust и потребность в социальных взаимодействиях.
