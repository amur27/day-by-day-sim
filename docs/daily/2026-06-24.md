- `Reputation` — Professional, Business, Social
- `Document` — Type, Issuer, IssueDate, ExpiryDate, Status
- `LegalCase` — Type, Subject, FilingDate, Status, PossibleOutcomes, LawyerRequired
- `Fine` — Reason, Amount, Issuer, DueDate, Status
- `Debt` — Creditor, Principal, InterestRate, MonthlyPayment, RemainingMonths, Collateral, PenaltyOnDefault
- `LegalStatus` — Documents[], Cases[], Fines[], HasCriminalRecord
- `PersonalFinances` — Cash, BankBalance, Debts[], Fines[], MonthlyIncome, MonthlyExpenses, NetMonthly
- `Education` — Level, Institutions[], Qualifications[], IsCurrentlyStudying

### Пересмотр модели здоровья — ключевое архитектурное решение

Исходная модель (`Health` с HP/Energy/Mood/Stress) заменена на два отдельных класса:

```
LifeStats
├── HP   — физическое здоровье  (0 = смерть)
└── MP   — духовное здоровье    (0 = смерть)
     IsDead => HP <= 0 || MP <= 0

Needs
├── Nutrition  → при ~0: дренаж HP
├── Energy     → при ~0: дренаж HP + MP
├── Mood       → при ~0: дренаж MP
└── Stress     → при >80: дренаж MP | при >95: события
```

Потребности не убивают напрямую — только через жизненные параметры.  
Обновлены: `CharacterData.cs`, `FamilyMember.cs`, `docs/characters.md`, `docs/entities.md`.

### Локализация (`scripts/core/L10n.cs`, `locales/`)

**L10n.cs** — статический хелпер над TranslationServer:
- `T(key)` — базовый перевод
- `T(key, args)` — с форматированием
- `Plural(key, n)` — множественная форма (русские падежи через PO plural rules)
- `SetLocale(locale)`, `CurrentLocale`

**locales/ru.po** и **locales/en.po** — ~90 ключей каждый:
- UI общее (close, back, confirm, cancel, yes, no)
- Время (pause, x1, x2, x4)
- Здания и районы (9 типов)
- Жизненные параметры (HP, MP)
- Потребности (Nutrition, Energy, Mood, Stress)
- 18 черт характера
- Диапазоны значений черт (loathes → adores)
- 14 типов отношений
- 7 уровней образования
- Занятость, финансы (с множественными формами для рублей)
- Правовые статусы (документы, дела, штрафы)
- Полярность привычек
- Системные сообщения (game over, family extinct)

Зарегистрированы в `project.godot` под `[internationalization]`, fallback = `en`.  
`BuildingPopup.cs` обновлён как пример использования `L10n.T()`.
