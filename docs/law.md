# Закон и бюрократия

## Роль в игре

Закон и бюрократия — отдельный игровой столп. Могут стать как препятствием, так и инструментом (карьера, власть, защита активов).

Сатира уместна. Последствия — серьёзны.

---

## Что входит в систему

| Элемент | Описание |
|---|---|
| Документы | Паспорт, ИНН, прописка, трудовая книжка, свидетельства |
| Договоры | Аренда, покупка, найм, кредит, бизнес-партнёрство |
| Налоги | Подоходный, на имущество, на бизнес, НДС |
| Штрафы | За административные нарушения, просрочки, нарушения правил |
| Лицензии | На ведение определённых видов бизнеса |
| Проверки | Налоговая, санитарная, пожарная, трудовая инспекция |
| Суды | Гражданские и уголовные дела |
| Наследство | Завещания, очерёдность, споры |
| Права на имущество | Регистрация, залог, арест |
| Регистрация бизнеса | Открытие, изменение формы, ликвидация |
| Взыскание долгов | Судебное и внесудебное |
| Государственные должности | Карьера в гос. структурах как особый путь |
| Связи | Ускоряют бюрократические процессы |
| Лоббирование | Влияние на решения через связи |
| Коррупция | Риск: может помочь, может уничтожить репутацию или привести к суду |
| Правовые обходы | Серые схемы — работают, пока не поймали |
| Нелегальные риски | Уголовная ответственность |

## Сущности

```
Document
├── type (паспорт / ИНН / лицензия / свидетельство...)
├── owner → FamilyMember | PlayerBusiness
├── issuer (орган выдавший документ)
├── issueDate
├── expiryDate (если применимо)
└── status (действителен / просрочен / аннулирован)

License
├── type (ресторанная / строительная / медицинская...)
├── business → PlayerBusiness
├── issueDate
├── renewalDate
└── status (активна / приостановлена / отозвана)

LegalCase
├── type (гражданское / уголовное / административное)
├── parties[] → FamilyMember | Corporation | State
├── subject (предмет спора)
├── filingDate
├── status (открыто / в процессе / закрыто / исполнение)
├── possibleOutcomes[]
└── lawyerRequired (нужен ли адвокат для защиты)

Fine
├── reason
├── amount
├── issuer
├── dueDate
└── status (оплачен / просрочен / оспаривается)
```

## Черты персонажа и закон

Черта **«Бюрократизм»** влияет на:
- скорость сбора и оформления документов
- качество подачи заявлений
- устойчивость к давлению инспекторов

Черта **«Отношение к закону»**:
- высокая (61–100): персонаж избегает нарушений, паникует от штрафов и проверок
- низкая (0–40): склонен к обходам, легче соглашается на коррупционные схемы, спокойнее реагирует на штрафы

Черта **«Любовь к общению»** / **связи**:
- влияет на доступность «нужных людей» в гос. структурах

## Примеры событий из системы закона

- налоговая проверка по бизнесу
- иск от арендодателя за неуплату
- наследственный спор между членами семьи
- уголовное дело за уклонение от налогов
- приостановка лицензии после санитарной проверки
- предложение дать взятку инспектору
- суд с бывшим партнёром по бизнесу

## MVP

В первой версии:
- базовые документы (необходимые для работы и бизнеса)
- налоги как ежемесячный платёж
- штрафы как результат событий
- одна-две лицензии для бизнеса
- судебные дела как длинные события с выборами

Лоббирование, коррупция и сложные уголовные дела — расширение после core loop.
