# Экономика

## Семейные финансы — центральная система

Деньги создают реальные развилки:
- дешёвое жильё vs плохие школы / транспорт
- дорогое образование vs долг
- инвестиции в бизнес vs финансовая безопасность семьи
- страховка vs краткосрочная экономия
- статусные траты vs долгосрочная стабильность
- законный путь vs рискованный обход

### Личные финансы

```
PersonalFinances
├── cash (наличные)
├── bankAccount (банковский счёт)
├── monthlyIncome (зарплата + дивиденды + аренда)
├── monthlyExpenses (аренда, коммуналка, еда, транспорт, кредиты, налоги)
├── savings (накопления)
├── ownedProperties[] → Building
├── ownedStocks{} → { corporation: sharesCount }
├── ownedBusinesses[] → PlayerBusiness
├── debts[] → Debt
└── assets[] → Asset
```

> Семья может иметь общий бюджет и/или личные счета — решается на уровне дизайна UI.

## Статьи расходов

| Статья | Описание |
|---|---|
| Аренда / ипотека | Ежемесячный обязательный платёж |
| Коммунальные услуги | Зависит от площади и состояния дома |
| Питание | Зависит от состава семьи и качества продуктов |
| Транспорт | Зависит от расстояния и способа перемещения |
| Образование | Курсы, университеты, репетиторы |
| Медицина | Плановые осмотры, лечение |
| Страховки | Жильё, здоровье, бизнес |
| Налоги | Подоходный, на имущество, на бизнес |
| Штрафы | За нарушения, суды, просрочки |
| Обслуживание имущества | Ремонт, техника, содержание бизнеса |
| Образ жизни | Рестораны, шоппинг, развлечения — растёт с доходом |

**Lifestyle inflation** — при росте доходов привычки и ожидания семьи растут. Возврат к экономии создаёт стресс у персонажей с высоким «отношением к комфорту» и «престижу».

## Кредиты и долги

```
Debt
├── creditor (банк / частное лицо / гос. орган)
├── principal (сумма долга)
├── interestRate (процент)
├── monthlyPayment
├── remainingMonths
├── collateral → Building | Asset (залог)
└── penaltyOnDefault (последствия невыплаты)
```

Последствия просрочки: штрафы → арест счетов → изъятие залога → суд → кредитная история.

## Корпорации

В городе существуют **крупные корпорации** — основа городской экономики и рынка труда.

```
Corporation
├── id
├── name
├── sector (IT / финансы / производство / торговля / медицина...)
├── buildings[] → Building
├── jobPositions[] → JobPosition
├── stock
│   ├── price
│   ├── priceHistory[]
│   └── sharesTotal
├── finances
│   ├── revenue
│   ├── expenses
│   └── profit
└── state (активна / банкротство / слияние)
```

Корпорации работают в фоне: их финансы меняются под влиянием событий (кризис, успешный продукт, скандал, слияние). Финансы корпорации прямо влияют на цену акций и количество вакансий.

---

## Биржа

Корпорации торгуются на бирже. Игрок может покупать и продавать акции через банк или приложение.

```
NewPrice = BaseFundamentalValue
         + MarketSentimentModifier
         + CorporationEventModifier
         + RandomNoise
```

Черта «Отношение к риску» влияет на склонность инвестировать в волатильные акции и эмоциональную реакцию на потери/прибыль.

## Работа

```
JobPosition
├── corporation → Corporation
├── building → Building
├── title
├── salary
├── schedule (рабочие часы)
├── requiredSkills{} (навык: минимальный уровень)
├── requiredEducation
├── requiredAge
└── careerPath[] (следующие ступени карьеры)
```

**Работа даёт:** доход, стресс, контакты, репутацию, навыки и будущие возможности.  
**Увольнение** возможно при нарушениях, сокращении, выгорании или конфликте.

## Бизнес игрока

```
PlayerBusiness
├── type (ресторан / магазин / студия / IT-компания...)
├── building → Building
├── owner → FamilyMember
├── employees[] → FamilyMember | NPC
├── licenses[] → License
├── finances
│   ├── revenue
│   ├── expenses
│   └── profit
├── reputation (влияет на клиентский поток)
└── inspectionRisk (вероятность проверки)
```

Бизнес может стать: источником дохода, семейным активом, репутационным двигателем, правовой ответственностью, наследственным объектом или источником семейного конфликта.

**Управление бизнесом через UI:**
- нанять / уволить сотрудников
- установить цены
- улучшить помещение
- получить или продлить лицензии
- просмотр финансовой отчётности

## Городская экономика

Макроэкономика города влияет на семью через:

| Фактор | Влияние |
|---|---|
| Рынок труда | Какие вакансии есть и по каким зарплатам |
| Зарплаты в индустрии | Потолок дохода в разных секторах |
| Цены на жильё | Стоимость покупки и аренды по районам |
| Инфляция района | Рост или падение цен в конкретном районе |
| Спрос на услуги | Прибыльность бизнесов игрока |
| Конкуренция | Другие бизнесы влияют на клиентский поток |
| Кризисы | Массовые увольнения, обвал акций, рост аренды |
| Регуляторное давление | Количество проверок и строгость штрафов |
| Качество инфраструктуры | Школы, медицина, транспорт меняются со временем |

Одна и та же семейная стратегия даёт разный результат в зависимости от района, момента времени и состояния городской экономики.
