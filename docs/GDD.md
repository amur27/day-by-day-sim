# Game Design Document — Day-by-day-sim

## Обзор

| Параметр | Значение |
|---|---|
| Жанр | 2D симулятор династии, sandbox |
| Движок | Godot 4 |
| Язык | C# |
| Вид | Изометрия 3/4, пиксель-арт |
| Платформа | PC (Desktop) |

**Концепция:** Игрок управляет семьёй в большом городе, строя династию через поколения. Работа, образование, недвижимость, бизнес, долги, репутация, закон, бюрократия и социальная мобильность — всё переплетается в живой городской симуляции. Нет финальной победы — история семьи пишется самим игроком.

**Формула игры:**  
**Dynasty + Economy + City + Character Traits + Law & Bureaucracy**

## Ключевые принципы дизайна

1. **Черты определяют исход, не ограничивают команды** — игрок всегда может отдать прямую команду; черта меняет качество и последствия, но не отменяет действие
2. **Последствия реальны** — банкротство, выселение, тюрьма, смерть, потеря бизнеса — не условности, а возможные финалы
3. **Город создаёт давление** — экономика района, рынок труда, конкуренция и городские события меняют условия жизни семьи без участия игрока
4. **Семья — единица стратегии** — ресурсы, репутация, долги и имущество могут передаваться между поколениями
5. **Глубина одной системы лучше ширины десяти** — сначала строим рабочий core loop, затем углубляем по одной системе

## Фантазия игрока

Игрок не просто поддерживает персонажа живым. Он формирует долгосрочное положение семьи в городе:

- выбирается из бедности или падает в неё
- переезжает между районами по мере роста или падения
- строит карьеры и получает квалификации через поколения
- открывает, развивает или теряет бизнесы
- покупает, улучшает, сдаёт или теряет недвижимость
- разбирается с документами, налогами, проверками, судами, лицензиями
- решает: действовать честно, обойти правила, использовать связи или рискнуть
- наблюдает как дети наследуют деньги, долги, репутацию, привычки, навыки и возможности

## Архитектура модулей

| Модуль | Ответственность |
|---|---|
| **Family** | Состав семьи, история династии, общее имущество, наследование |
| **Character** | Характеристики, навыки, потребности, здоровье, привычки, отношения |
| **City** | Районы, здания, маршруты, услуги, городская экономика |
| **Economy** | Финансы домохозяйства, рынки, долги, налоги, платежи, активы |
| **Activity** | Еженедельные планы, прямые команды, путешествия, работа, учёба, быт |
| **Event** | Детекция триггеров, генерация событий, выбор решений, применение последствий |
| **Business** | Бизнесы, сотрудники, спрос, поставки, лицензии, прибыль, проверки |
| **Law** | Правовой статус, документы, дела, штрафы, лицензии, договоры, суды |
| **UI** | Карта города, панель семьи, карточки персонажей, план, команды, отчёты |

## Поток данных

```
Игрок редактирует еженедельный план или отдаёт прямую команду
    ↓
Activity module: проверяет физическую возможность, тратит время / деньги / энергию / транспорт
    ↓
Черты и навыки персонажа: модифицируют качество, стресс, риск, побочные эффекты
    ↓
Economy / City / Business / Law / Relationships / Health: применяют изменения
    ↓
Event module: проверяет триггеры событий
    ↓
UI: показывает обратную связь, движение по карте, выбор событий, отчёты
```

Прямые команды имеют приоритет над автоматическим поведением по плану.
