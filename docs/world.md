# Мир и город

## Структура города

Город — большая 2D-карта с зумом. Дизайн сочетает:
- **Мозаику районов** как первичную структуру (видна с дальнего зума)
- **Конкретные важные здания** внутри районов (видны при приближении)

Город генерируется **один раз при создании новой игры** и сохраняется.

---

## Районы

При дальнем зуме игрок видит районы. Каждый район — отдельная игровая среда со своими параметрами.

| Район | Описание |
|---|---|
| **Бедный** | Дешёвое жильё, высокая преступность, плохая инфраструктура |
| **Спальный** | Жилые дома, школы, магазины, средний класс |
| **Промышленный** | Заводы, склады, рабочие места, низкий престиж |
| **Деловой** | Офисы, банки, рестораны бизнес-класса |
| **Университетский** | Вузы, кафе, молодёжная среда, дешёвое жильё |
| **Торговый** | Магазины, рестораны, развлечения |
| **Элитный** | Дорогое жильё, безопасность, высокий престиж |
| **Пригород** | Частные дома, низкая плотность, далеко от центра |
| **Смешанный** | Переходная зона, нестабильные характеристики |

**Параметры района (влияют на жизнь семьи):**

| Параметр | Влияние |
|---|---|
| housingPrice | Стоимость покупки жилья |
| rentLevel | Уровень аренды |
| prestige | Влияет на персонажей с высоким «отношением к престижу» |
| safety | Вероятность преступлений, влияние на страховку |
| transportQuality | Скорость и стоимость поездок |
| ecology | Влияет на здоровье при длительном проживании |
| schoolQuality | Скорость обучения детей |
| medicineQuality | Эффективность лечения в районных клиниках |
| jobAvailability | Сколько вакансий доступно в районе |
| businessDemand | Спрос на услуги бизнесов игрока |
| inspectionPressure | Частота налоговых и административных проверок |
| socialEnvironment | Тип социальных контактов доступных в районе |
| growthTrend | Признак: район растёт, стагнирует или деградирует |

## Важные здания

При приближении карта показывает конкретные здания. Первая версия не симулирует каждое здание в городе — только важные локации, с которыми семья реально взаимодействует.

| Тип здания | Функция |
|---|---|
| Жилой дом / квартира | Проживание семьи |
| Школа | Образование детей |
| Университет / колледж | Высшее образование, курсы |
| Больница | Лечение, плановые осмотры |
| Офис / бизнес-центр | Рабочее место (корпорации) |
| Завод | Производство, рабочие места |
| Магазин / супермаркет | Покупка товаров |
| Банк | Кредиты, счета, инвестиции |
| Суд | Судебные дела |
| Гос. учреждение | Документы, лицензии, регистрация |
| Спортивный объект | Физические навыки, здоровье |
| Культурная локация | Отдых, творчество, социальные контакты |
| Бизнес-локация | Место для бизнеса игрока |

**Поля здания:**

```
Building
├── id
├── name
├── type
├── district → District
├── position (координаты на карте)
├── owner (игрок / корпорация / город)
├── purchasePrice
├── rentPrice
├── openingHours (расписание работы)
├── slots[] (рабочие места / квартиры / столики)
├── prestige
└── condition (влияет на цену и функциональность)
```

## Путешествия

Перемещение между зданиями имеет значение. Не телепортация — логистика.

**Путешествие влияет на:**

| Параметр | Описание |
|---|---|
| Время | Сколько игрового времени уходит |
| Деньги | Стоимость транспорта |
| Усталость | Энергия тратится в дороге |
| Опоздание | Если маршрут не учтён, персонаж опаздывает на задачу |
| Настроение | Плохой транспорт и долгие поездки снижают настроение |
| Безопасность | В плохих районах и ночью выше риск события |
| События | Поездки — источник случайных встреч и событий |
| Доступ к возможностям | Близость к нужным зданиям открывает возможности |

**Местоположение жилья — стратегическое решение, не только визуальное:**
- Дешёвое жильё в плохом районе экономит деньги, но тратит время и здоровье
- Элитный район — высокие расходы, но качество школ, медицины и социальных контактов

## Дом как система

Семейный дом — три вещи одновременно: база для потребностей, улучшаемый объект, актив династии.

**Системы дома:**

| Категория | Влияние |
|---|---|
| Качество кухни | Питание, здоровье, настроение |
| Спальни | Качество сна, восстановление энергии |
| Ванная / гигиена | Здоровье, настроение, репутация на работе |
| Комфорт | Персонажи с высоким «отношением к комфорту» деградируют в плохих условиях |
| Безопасность | Риск происшествий дома |
| Рабочее место / кабинет | Скорость удалённой работы и обучения |
| Детская зона | Скорость развития детей |
| Ремонтное состояние | Падает со временем, влияет на стоимость и функциональность |
| Престижность | Влияет на персонажей с высоким «отношением к престижу» и на гостей |
| Энергоэффективность | Размер коммунальных счетов |

**Улучшения — по категориям, не по предметам вручную.** Игрок выбирает что улучшить (кухню, ванную, рабочее место), а система применяет эффекты.

**Имущество можно:**
- арендовать (ежемесячный платёж)
- купить (ипотека или полная оплата)
- улучшать
- продать
- сдавать в аренду (пассивный доход)
- передать по наследству
- потерять (за долги или по суду)

## Время суток и активность

- Здания работают по расписанию (открыто/закрыто)
- День/ночь влияет на доступность задач и безопасность маршрутов
- Персонажи видимо перемещаются по карте к целям
